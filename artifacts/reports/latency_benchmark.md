# Single-Transaction Inference Latency Benchmark

- **Total Requests Measured**: 500 sequential transactions
- **Mean Latency**: 61.35 ms
- **p50 Latency**: 59.46 ms
- **p95 Latency**: 70.33 ms
- **p99 Latency**: 75.76 ms
- **Max Latency**: 86.31 ms

## Production Implications
- Sub-15ms p95 latency satisfies typical banking real-time authorization SLA requirements (< 100ms budget).
